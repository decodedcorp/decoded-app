### 1.2 홈 및 탐색 (Discovery) - *계층형 필터 적용*

단순 카테고리가 아닌, 구매로 이어지는 딥 다이브(Deep-dive) 탐색을 지원합니다.

| ID | 기능명 | 상세 설명 | 우선순위 |
| --- | --- | --- | --- |
| **D-01** | **반응형 매거진 피드** | [Mobile] 숏폼 스타일 / [Web] 핀터레스트 그리드 스타일. | P0 |
| **D-02** | **계층형 필터 (Deep Filter)** | 단순 필터가 아닌 **Drill-down 방식**의 UI 제공.<br>예: `K-POP` 선택 -> `BTS` 선택 -> `정국` 선택 -> `공항패션` 선택 시 해당 결과만 노출. | P0 |
| **D-03** | **미디어/작품관** | `오징어게임`, `솔로지옥` 등 특정 **작품(Title)**을 기준으로 묶어보는 전용 페이지. | P1 |
| **D-04** | **통합 검색** | 키워드 검색 시 **[인물]**, **[작품]**, **[아이템]** 탭으로 구분하여 결과 제공.<br>예: "지수" 검색 -> 블랙핑크 지수(인물), 지수 착용 가방(아이템) 분리 노출. | P0 |

## 3. 핵심 변경 포인트 요약 (Summary of Changes)

1. **DB 구조화 (Hierarchical Data):**
    - 기존: `게시글` -> `카테고리(패션)` (단순)
    - 변경: `게시글` -> `미디어(오징어게임)` -> `인물(정호연)` -> `카테고리(패션)` (입체적)
    - *효과:* "오징어게임에 나온 그 초록색 옷"처럼 맥락기반 검색이 가능해짐.
2. **팬덤 뱃지 시스템 (Specialist Badges):**
    - 기존: `Hunter` (단순 등급)
    - 변경: `IVE Expert`, `G-Dragon Master` (구체적 칭호)
    - *효과:* 팬들이 "내 가수의 패션 정보는 내가 제일 잘 알아"라는 자부심을 갖고 활동하게 함.

이 기능 명세서를 개발팀에 전달하면, **DB 설계 단계(Schema Design)**에서부터 작품(Media)과 인물(Person) 테이블을 분리하여 설계하게 될 것입니다. 아주 중요한 디테일을 잘 잡으셨습니다!
