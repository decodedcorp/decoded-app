Create the MagazineBook component -- a single 3D book object.

**Props:** `{ issue: MagazineIssue; position: [number, number, number]; rotation?: [number, number, number]; isOpen?: boolean; opacity?: number }`

**Structure (group hierarchy):**
```
<group position={position} rotation={rotation}>
  <!-- Main body: box for spine + back + pages -->
  <mesh>
    <boxGeometry args={[1, 1.5, 0.15]} />  // 2:3 aspect, 0.15 depth
    // 6 materials: right, left, top, bottom, front, back
    material-0 through material-3: #1a1a1a (dark sides)
    material-4: transparent or omitted (front cover is separate mesh)
    material-5: #0a0a0a (back cover)
  </mesh>

  <!-- Front cover: separate plane on pivot group for flip animation -->
  <group ref={coverRef} position={[-0.5, 0, 0.076]}>
    <mesh position={[0.5, 0, 0]}>
      <planeGeometry args={[1, 1.5]} />
      <meshStandardMaterial map={coverTexture} side={DoubleSide} />
    </mesh>
  </group>

  <!-- Spine label: Drei <Text> on left face -->
  <Text
    fontSize={0.08}
    color="#eafd67"
    anchorX="center"
    anchorY="middle"
    rotation={[0, Math.PI / 2, Math.PI / 2]}
    position={[-0.575, 0, 0]}
  >
    Vol.{padded issue_number}
    <meshStandardMaterial emissive="#eafd67" emissiveIntensity={2.0} toneMapped={false} />
  </Text>
</group>
```

**Cover texture:** Use Drei `useTexture(issue.cover_image_url)`. Handle loading via React Suspense (useTexture auto-suspends).

**Cover flip:** Use `useGSAP` to animate coverRef.rotation.y based on `isOpen` prop. Open: rotateY 0 -> -PI/6 (0.5s, power2.out). Close: -PI/6 -> 0 (0.3s). The isOpen prop will be driven by studioStore.focusedIssueId in Plan 03.

**Opacity:** When opacity prop < 1, set all materials' opacity and transparent=true. This is used when another book is focused (non-focused books fade to 0.3).

**Hover handlers (placeholder):** Add onPointerOver/onPointerOut/onClick as props (callbacks passed from MagazineRack). Actual hover glow logic comes in Plan 03 -- for now just wire the event props.

**IMPORTANT:** Do NOT use `attachArray` (removed in R3F v8). Use indexed `attach="material-N"` syntax.
